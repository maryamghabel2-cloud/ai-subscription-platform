# ADR 0001: Canonical Commercial Roadmap

## Status
Owner Approved

## Date
2026-08-11

## Author
Owner / Product Architecture

## Context
The legacy subscription-reseller direction and prior roadmap no longer match the
accepted Persian AI Business Automation and Creator Commerce Platform direction.
Older recovery and roadmap documents contain planning states that conflict with
current code foundations and commercial decisions.

## Decision
Adopt the canonical five-phase roadmap: Phase 0 Foundation Completed; Phase 1 Core
Product MVP In Progress; Phase 2 Commercial Studio Planned; Phase 3 Marketplace
Planned; Phase 4 Agent Platform Planned; Phase 5 Scale, Channels, and Enterprise
Future.

## Consequences
Backlog work follows Phase 1 priorities. The frontend is treated as legacy/incomplete
until replaced and validated. Existing foundations are validated rather than rebuilt.
Legacy and recovery documents are Historical unless canonical documents reference
them.

## Alternatives Considered
The old MASTER_ROADMAP was insufficient because it predates the commercial pivot.
Draft PR #31 was insufficient because it created a competing roadmap and contained
repetitive filler rather than a canonical replacement.
