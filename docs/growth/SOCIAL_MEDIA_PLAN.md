# SOCIAL MEDIA PLAN

**Date:** 2026-07-19

## Channels

- Instagram: Before/after product photos, short video demos
- Telegram Channel: Product updates, tips, not spam
- Twitter/X (optional): Dev updates
- LinkedIn: Business agents, API platform (future)

## Content Pillars

- Product demos (studio before/after)
- Prompt tips (Persian)
- Persona spotlights (how to use career advisor)
- Behind the scenes building (founder building with agents)

## Workflow (Draft-Only, Human Publishes)

1. Social Media Agent drafts posts for week (captions, hashtags, image ideas) → markdown report
2. Growth Marketing reviews
3. Founder approves (approval gate for publishing public content)
4. Founder or human manually publishes (no auto-publish)

## Calendar (Idea)

- Monday: Prompt tip
- Wednesday: Product studio demo
- Friday: Persona spotlight
- No bulk messaging without approval

## Safety

- No auto-publishing
- No contacting customers via DM without approval
- No medical/legal advice without disclaimer
- All posts have draft footer until approved

## Metrics

- Follower growth, engagement, link clicks to landing, signup from social

## Tools

- Now: External agent drafts in Google Docs/markdown
- Later L3: Draft CMS creates scheduled drafts, human publishes
