# LAUNCH PLAN

**Date:** 2026-07-19

## Phases

### Pre-Launch (Phase 0-1)
- Docs + MVP skeleton local via docker compose
- Landing page local
- No public launch yet

### Soft Launch (Phase 1 Core MVP)
- Deploy to staging (future, not now)
- Invite 10-20 beta users (friends, Telegram group)
- Collect activation feedback
- No paid ads yet, organic only

### Public Launch (Phase 2-3)
- Product Hunt (Persian community equivalent), relevant Telegram channels, Instagram
- Launch with: general chat + prompt enhancer + 5 personas + product photography studio
- Blog posts ready, SEO basics

### Growth Launch (Phase 4+)
- API Platform launch for developers
- Telegram Business Agents launch

## Channels

- SEO (primary)
- Content (blog)
- Telegram channels (community)
- Instagram (product photography before/after)
- Referral (future)

## Launch Checklist (For Each Phase Launch)

- [ ] Feature meets exit criteria from phase doc
- [ ] QA Security tests pass, no P0 vulnerabilities
- [ ] Persona QA/red teaming passed (if personas)
- [ ] Human approval gates checked (no auto-publish, no auto-spend)
- [ ] Pricing page correct, wallet logic tested, no mock payment
- [ ] Landing page + blog posts approved and published manually
- [ ] Analytics events firing
- [ ] Support FAQ ready, support draft replies ready (not auto-send)
- [ ] Rollback plan documented
- [ ] Founder approved launch via issue comment

## Metrics for Launch

- Visits, signup conversion, activation, credit purchase (if payment live), retention

## Safety
- No launch without human approval
- No paid campaigns auto-launch
