# Threat Model

**Purpose:** Define threat model, assets, attackers, attack vectors, and mitigations for the platform.

**Status:** Draft - Structure Only

**Note:** This is a structure-only stub. Final threat model will be completed in later PRs with reviewed policies.

## Scope

This document will cover:

- Assets: user accounts, wallets, ledgers, payment intents, conversations, uploaded files, API keys, prompts, generated content
- Attackers and motivations: external attackers, malicious users, compromised agents, supply-chain
- Attack vectors: authentication bypass, injection, prompt injection, data exfiltration, payment fraud, abuse of agents, channel spoofing
- Trust assumptions and non-goals
- Mitigations mapped to security controls
- Risk rating and prioritization

Final policy will require security architect, product-owner, and privacy review.
