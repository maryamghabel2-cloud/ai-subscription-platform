# Documentation Canonical Index

## Single Source of Truth

- [Current Implementation Status](CURRENT_IMPLEMENTATION_STATUS.md): code/test evidence matrix.
- [Master Roadmap](roadmap/MASTER_ROADMAP.md): canonical phase ordering.
- [ADR 0001](decisions/0001-canonical-commercial-roadmap.md): commercial roadmap decision.
- [Commercial Direction](product/COMMERCIAL_AGENT_SKILL_AND_CREATOR_PLATFORM_DECISIONS.md): owner-approved product direction.

## Documentation Maturity States

- **Draft:** working material without approval.
- **Proposed:** candidate architecture or policy awaiting approval.
- **Owner Approved:** direction approved by the owner, not implementation proof.
- **Implemented:** code artifacts exist and are linked as evidence.
- **Verified:** implementation evidence has been executed and recorded.
- **Deprecated:** retained but not recommended for new work.
- **Superseded:** replaced by a named canonical document.
- **Historical:** retained context, not a current product requirement.

## Reading Order for AI Agents

1. Read this index and Current Implementation Status.
2. Read the Master Roadmap and ADR 0001.
3. Read applicable product/architecture/security documents.
4. Treat historical recovery documents as context only.
5. Do not infer implementation from planned or approved documentation.

## Historical / Superseded Documents

`MVP_RECOVERY_PLAN.md`, technical audits, legacy recovery plans, and reseller-era
materials are Historical unless a canonical document explicitly promotes them.
If archival movement occurs later, `docs/archive/` is the destination; these files
are not deleted by this baseline.
