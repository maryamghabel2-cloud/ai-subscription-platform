# PRODUCT VISION - Persian AI Platform

**Version:** Phase 0 Draft  
**Date:** 2026-07-19  
**Status:** Foundation Planning  
**Branch:** docs/phase-0-agent-operating-system

## Vision Statement

Build a **Persian-first AI Workspace** that helps Iranian creators, businesses, developers, and everyday users work smarter with AI - from general chat and prompt engineering to product photography, video generation, Telegram business agents, and developer APIs.

We are **not** a subscription reseller. We are a product platform with our own user accounts, wallet/credit billing, agent system, and growth loops.

## Problem Summary

- Persian users face language, payment, and access barriers to global AI tools
- Existing tools are fragmented: chat here, image there, video elsewhere
- No unified billing, no persona system tailored for Persian business context
- No simple way for businesses to deploy Telegram agents or product studios

## Solution Principles

1. **Persian-first UX** but global-quality AI
2. **Credit-based billing** via wallet - simple, transparent, no shared accounts
3. **Persona system** - general chat + evidence-based specialist assistants (research-backed, not authoritative)
4. **Studio workflows** - product photography, image generation, video generation, character tools as guided studios
5. **Telegram & Business Agents** - low-code agents that run in Telegram or business workflows
6. **Developer API Platform** - own APIs for chat, image, RAG
7. **Agent Operating System** for building the product itself (external agents now, internal later)

## What This Platform Is Not (De-scoped Legacies)

- ❌ Not a reseller of shared Netflix/GPT accounts - deprecated model
- ❌ Not automated procurement from GGSel/FunPay
- ❌ Not crypto payment at Phase 0/1
- ❌ No bypassing provider ToS, KYC, or geographic pricing tricks

## User-Facing Product Areas (Future)

- General Persian Chat
- Prompt Enhancer
- Specialist Personas (evidence-based)
- Image Generation Studio
- Product Photography Studio
- Video Generation
- AI Character / Influencer Tools
- Telegram Agent Integration
- Wallet & Credit Billing
- Developer APIs
- Business Agents (sales, support, content)
- Research & RAG Systems
- Agent Marketplace (Phase 8)

## Success Metrics (North Star)

- Activation: User signs up → completes first chat → buys credits → uses studio
- Retention: Weekly active users who use 2+ tools
- Business: Credit purchase conversion, LTV, referral loop

## Non-Goals for Phase 0

- Building production AI models from scratch
- Medical/legal/psychological diagnosis or authoritative advice
- Fully autonomous agents that spend money or publish without approval
