# USER PERSONAS - Persian AI Platform (Product Users, Not Agents)

**Date:** 2026-07-19

## Creator (Primary)

- **Who:** Instagram seller, small shop owner, content creator, 22-35, Tehran/Isfahan/Mashhad
- **Jobs:** Needs product photos, captions, video ads, but no studio budget
- **Pain:** Fragmented tools, English UI, expensive subscriptions
- **Our promise:** Product Photography Studio + Prompt Enhancer + Instagram Strategist persona
- **Activation:** Uploads product → gets 5 enhanced photos + captions in 10 minutes

## Business Owner (Secondary)

- **Who:** 30-45, runs online store, uses Telegram for support/sales
- **Jobs:** Wants Telegram bot that answers FAQs, qualifies leads
- **Pain:** No dev team
- **Our promise:** Telegram Business Agent builder, sales advisor persona

## Developer / Indie Hacker

- **Who:** 25-35, builds Persian products
- **Jobs:** Needs Persian chat API, image API, RAG for docs
- **Pain:** No Persian-first API with simple billing
- **Our promise:** Developer API Platform, clear docs, credit billing, logs

## Researcher / Student

- **Who:** Student, researcher, needs RAG over PDFs, evidence-based summaries
- **Jobs:** Upload papers, ask questions, get cited answers
- **Pain:** GPT hallucinates, no Persian academic context
- **Our promise:** Research assistant persona with citations, RAG attachment, no authoritative claims

## Excluded Personas (Phase 0)

- End-users seeking medical diagnosis, legal verdict, psychological therapy - we provide evidence-based assistant information, not authority. Escalation to professional required.

## How User Personas Link to Specialist Personas

- Creator → Product Photography Advisor, SEO Advisor, Instagram Strategist
- Business Owner → Sales Advisor, E-commerce Advisor, Business Automation Advisor
- Developer → Prompt Engineer persona, API docs
- Researcher → Researcher persona with RAG
