# LANDING PAGE REQUIREMENTS

**Date:** 2026-07-19

## Home Landing

- **Hero:** H1 Persian: "فضای کاری هوش مصنوعی فارسی برای سازندگان و کسب‌وکارها" (example), sub-headline benefit, CTA Register + Secondary CTA Watch Demo (future video)
- **Logos:** Future social proof
- **Tools Overview:** 6 cards: Chat, Personas, Product Studio, Telegram Agents, API, Business Agents - each with icon, short desc, link
- **How It Works:** 3 steps: 1. ثبت نام 2. انتخاب ابزار 3. ساخت و دریافت
- **Use Cases:** Clothing store product photos before/after, Telegram bot FAQ demo
- **FAQ:** 5 questions with Schema FAQPage, e.g., "آیا این پزشکی است؟" → Must answer with disclaimer
- **Final CTA:** Register
- **Footer**

## Tool Landing (e.g., /product-studio)

- Hero specific to tool: "عکاسی محصول با هوش مصنوعی - ۵ عکس استودیویی در ۱۰ دقیقه"
- Demo: Upload mock, before/after
- Features: 3 bullets
- How it works: upload → settings → generate
- Persona embedded: Product Photography Advisor tip
- Pricing teaser: credit cost per image
- FAQ tool-specific
- CTA to studio or register

## SEO Requirements per Landing

- Meta title 50-60 chars Persian, includes primary keyword
- Meta description 150-160 chars with CTA
- H1 one, H2 sections
- Alt text for images descriptive with keyword natural
- Internal links: link to related personas, blog, other tools
- Schema: Organization + Product (if applicable) + FAQPage + BreadcrumbList
- Core Web Vitals: LCP <2.5s, CLS <0.1

## Approval Workflow

- Website Builder creates branch with landing file
- PR includes SEO checklist: title, desc, H1, alt, internal links, schema, disclaimer if persona page
- Growth + SEO review
- Human approval → merge → deploy

## Safety

- No guarantee claims like "تضمینی رتبه ۱ گوگل" or "تضمینی شغل"
- Persona landing includes disclaimer + risk level + escalation behavior
